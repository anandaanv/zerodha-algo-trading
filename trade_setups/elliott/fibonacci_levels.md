# Fibonacci Retracements and Extensions

## What they are
Mathematical ratios derived from the Fibonacci sequence that appear repeatedly at wave turning points. Used to project where corrections will end (retracements) and where impulses will reach (extensions).

---

## Retracement Levels

Used to project where a corrective wave will end before the trend resumes.

| Level | Meaning |
|-------|---------|
| 23.6% | Shallow pullback — usually only in very strong trends |
| 38.2% | Classic Wave 2 shallow retrace, or Wave 4 in strong trends |
| 50.0% | Psychological level — not a true Fibonacci ratio but widely respected |
| 61.8% | The "golden ratio" — classic Wave 2 retrace level |
| 78.6% | Deep retrace (√0.618) — last level before 100% invalidation |

### Formula (for an UP swing, retracing from high H to low L):
```
Level at X% = H − (X × (H − L))
```

---

## Extension Levels

Used to project where the next impulse wave will reach.

| Level | Meaning |
|-------|---------|
| 100% | Wave C = Wave A, Wave 5 = Wave 1 |
| 127.2% | Moderate extension |
| 161.8% | Classic Wave 3 extension (golden ratio), strong Wave C |
| 200% | Double extension — strong trending market |
| 261.8% | Extended Wave 3 in very powerful trends |

### Formula (from an origin O, with base swing B):
```
Target at X% = O + (X × B)
```

---

## How retracement depth classifies wave context

| Retrace depth | Category | Typical wave |
|---------------|----------|-------------|
| < 20% | NONE | Not a meaningful pivot |
| 20–38.2% | SHALLOW | Minor correction, strong trend |
| 38.2–65% | B_WAVE | Typical corrective structure |
| 65–78.6% | DEEP | Deep correction, potential structure change |
| > 78.6% | OVERSHOT | Near full retrace — re-label may be needed |

---

## Confluence zones

When multiple Fibonacci levels from different swings cluster near the same price, that zone has higher significance:
- A price level where a 61.8% retrace of one swing overlaps with a 38.2% retrace of another = high-confidence support/resistance.
- Confluence zones are scored by: number of overlapping factors × type diversity (fib + S/R = stronger than fib + fib alone).

---

## Application in Elliott scoring

In the impulse wave scorer, Fibonacci ratios are checked with tolerance bands:
- Within **±5%** of ideal ratio: full points
- Within **±10%**: partial points
- Within **±15%**: minimal points
- Beyond ±15%: 0 points for that ratio

Wave 3 extension gets the **highest weight** (16 pts max) because the 1.618 extension of Wave 1 is the most reliable and important ratio in Elliott analysis.
